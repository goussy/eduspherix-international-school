# EduSpherix International School — Demo Website

A clean, responsive, multi-page school website based on the supplied Terdal school website reference. The school identity has been changed to **EduSpherix International School**.

## Run locally
1. Extract this ZIP folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. The site uses shared CSS and JavaScript in `assets/`.

## Pages
- Home
- About the School
- Academics
- Admissions
- Facilities
- Activities
- Achievements
- Gallery (with working category filters)
- News & Events
- Contact
- Privacy Policy
- Terms & Conditions
- 404 page

## Functional behaviour
- Responsive navigation menu for mobile.
- Active navigation state.
- Gallery category filters.
- Admission and contact forms open WhatsApp with pre-filled enquiry details.
- Click-to-call and click-to-email links.
- Back-to-top button.

## Important before production
This package is prepared for demonstration and team review. Replace the sample campus address, school profile, curriculum/board details, events, achievements, office hours and stock photographs with verified school information and school-owned images. The forms currently hand off to WhatsApp; they do not save data to a backend. The gallery uses remote Unsplash demo images and therefore requires an internet connection for those photographs.
